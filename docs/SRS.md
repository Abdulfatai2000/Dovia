# Dovia requirements

Dovia turns conversations into tracked execution.

Create Meeting → Prepare Meeting → Conduct Meeting → Add Notes/Transcript → AI Analysis → Human Review → Confirm Decisions & Action Items → Assign Owners and Deadlines → Track Tasks → Follow-up Progress → Next Meeting.

Core rule: Meeting → Decision → Action Item → Owner → Deadline → Progress → Follow-up → Next Meeting. Dovia is more than a meeting summarizer.

Phase 0 provides routes, layouts, component placeholders, types, and documentation only. Database, authentication, AI, integrations, and full UI are deferred. AI drafts require human confirmation before final tasks are created.
